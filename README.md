# Детский сад «Кролик и часы»

Одностраничный лендинг частного детского сада (Красноярск).

## Просмотр

- Локально: откройте `krolik-i-chasy.html` (или `index.html` → редирект).
- GitHub Pages: корень репозитория, entry `index.html`.

Стили и скрипты — в одном HTML. Шрифты (Google Fonts: Nunito, Comfortaa) нужен интернет; фото пространства — в `photos/web/`.

## Содержимое

- Герой-блок с маскотом и фото игровой
- Навигация: Преимущества · **Пространство** · Режимы · Тарифы · Контакты
- Преимущества (bento-плитки), в т.ч. фото именных домиков-шкафчиков
- **Галерея «Загляните внутрь»** — 4 фото с lightbox (клавиатура, свайп)
- CTA «Приходите на экскурсию» + WhatsApp
- Блок «Что важно родителям» и мини-таймлайн дня
- Расписание, тарифы, интерактивы (календарь, seesaw, hop)
- Контакты, FAB-кнопки звонка/WhatsApp на мобильных

Исходники и PNG — в `photos/`. Для веба: JPEG до ~1600px, q≈85. Стрелки UI с исходных скриншотов убраны.

## Технологии

Чистый HTML + CSS + JS, без сборки и внешних JS-библиотек. Дизайн: мягкая палитра (`--pink`, `--mint`, `--gold`), скругления 24–28px, airy whitespace.
