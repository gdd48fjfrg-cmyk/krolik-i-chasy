# Детский сад «Кролик и часы»

Одностраничный лендинг частного детского сада (Красноярск).

## Просмотр

Откройте файл `krolik-i-chasy.html` в браузере или через GitHub Pages.

Всё в одном HTML-файле (стили, скрипты, встроенные изображения). Для шрифтов нужен интернет (Google Fonts); остальное работает офлайн.

## Содержимое

- Герой-блок, навигация, преимущества
- Расписание / график
- Тарифы
- Интерактивные элементы (календарь дней, анимации)

## Технологии

Чистый HTML + CSS + JS, без сборки и внешних JS-библиотек.
